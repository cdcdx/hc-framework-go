## 术语表（Glossary）
- **L1 / L2 / L3**：三级缓存（进程内 Ristretto / Redis / 主存储）
- **SRS**：需求规格说明书（[002_需求规格说明书.md](002_需求规格说明书.md)）
- **SSOT**：Single Source of Truth，单一来源
- **PDB**：Pod Disruption Budget（pod 中断预算）
- **MGR**：MySQL Group Replication（MySQL 组复制）
- **CH**：ClickHouse（监控库）
- **ES**：Elasticsearch（日志/审计库）
- **MQ**：消息队列（Kafka）
- **HA**：High Availability（高可用）
- **JWT**：JSON Web Token（认证令牌）
- **CAPTCHA**：人机验证码（防水墙）
- **K8s**：Kubernetes
- **LB**：Load Balancer（负载均衡）
- **IOPS / QPS / TPS**：存储 IO 每秒 / 每秒查询数 / 每秒事务数
- **TTL**：Time To Live（生存时间）
- **ER**：Entity Relationship（实体关系）
- **HPA**：Horizontal Pod Autoscaler（水平 Pod 自动扩缩）
- **StatefulSet**：K8s 有状态工作负载（稳定网络标识/存储，承载扫描分片）
- **Ingress**：K8s 外部流量接入（域名/LB）
- **RBAC**：基于角色的访问控制
- **Pod**：K8s 最小调度单元
