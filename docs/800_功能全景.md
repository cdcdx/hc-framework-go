## 三、流量治理

`internal/middleware/` · 源码约 38K + 测试 28K

防护链路：`Recovery → Timeout → Trace → RequestInfo → Logger → CORS → Metrics → ConcurrencyLimit → RateLimit → Auth → CircuitBreaker → Captcha → Security`

| 层 | 机制 | 维度 | 超限响应 | 状态 |
|:---|------|------|:---------:|:----:|
| 连接级上限 | `connlimit.go` 拦截 Accept | 全局 MaxConns / 单 IP MaxConnsPerIP | 断连 | ✅完整 |
| 有界并发/负载卸载 | `semaphore.Weighted.TryAcquire` 非阻塞 | 进程级在途请求硬上限 | 503 | ✅完整 |
| 令牌桶限流 | `golang.org/x/time/rate` | 全局 + 按用户 + 按 IP + 白名单 | 429 + Retry-After | ✅完整 |
| 熔断 | `sony/gobreaker` 三态 | 按路由分组，仅 ≥500 计失败 | 503 + 联动全局降级 | ✅完整 |
| 请求超时 | ctx deadline | 全局 `server.request_timeout` | 504 CodeGatewayTimeout | ✅完整 |
| 全局降级 | `internal/degrade` | 多熔断器打开计数 | 读跳过 L2 / 写转异步 | ✅完整 |
| 安全 IP 限流 | 滑动窗口 | register_per_minute / login_per_minute | 429 | ✅完整 |
