# 902 · 配置参考(go-zero 版)

两个配置文件:`app/gateway/api/etc/gateway.yaml`(网关)与 `app/rpc/etc/hc.yaml`(领域 rpc)。
均为 YAML,由 go-zero `conf.MustLoad` 加载;`time.Duration` 字段支持 `1h`/`30m`/`720h` 等格式。

## 1. app/rpc/etc/hc.yaml

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| Name | string | hc.rpc | 服务名(etcd 注册 Key 前缀) |
| ListenOn | string | 0.0.0.0:8001 | gRPC 监听地址 |
| Etcd.Hosts | []string | [127.0.0.1:2379] | etcd 地址 |
| Etcd.Key | string | hc.rpc | 注册 Key(网关按此发现) |
| DB.Driver | string | sqlite | sqlite / mysql / postgres |
| DB.Dsn | string | data/hc.db | 连接串(sqlite=文件路径;mysql/postgres 用标准 DSN) |
| Jwt.Algorithm | string | HS256 | HS256 / RS256 |
| Jwt.SigningKey | string | - | HS256 签名密钥(生产必改) |
| Jwt.Issuer | string | hc-framework | token 签发者 |
| Jwt.AccessTTL | duration | 1h | access token 有效期 |
| Jwt.RefreshTTL | duration | 720h | refresh token 有效期 |
| Jwt.PrivateKeyPath / PublicKeyPath | string | "" | RS256 时必填,PEM 路径 |
| GoogleOAuth.ClientID | string | "" | Google OAuth Client ID |
| GoogleOAuth.ClientSecret | string | "" | Google OAuth Secret |
| GoogleOAuth.RedirectURI | string | "" | 授权回调地址 |
| Idle.MaxActiveDevices | int | 3 | 每用户最大并发挂机设备数 |
| Idle.PointsPerMinute | int | 1 | 挂机每分钟积分 |
| Idle.DailyPointsLimit | int64 | 240 | 每日挂机积分上限 |
| Prometheus.Host / Port | - | 0.0.0.0:9101 | 指标暴露端点 |
| Telemetry.Name | string | hc.rpc | 链路追踪服务名 |

启动:`cd app/rpc && go run hc.go -f etc/hc.yaml`(或 `make run-hc`)。

## 2. app/gateway/api/etc/gateway.yaml

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| Name | string | gateway-api | 服务名 |
| Host | string | 0.0.0.0 | HTTP 监听地址 |
| Port | int | 8080 | HTTP 端口 |
| Auth.Jwt.Algorithm | string | HS256 | **必须与 hc-rpc 一致**,否则 token 无法互通 |
| Auth.Jwt.SigningKey | string | - | **必须与 hc-rpc 一致** |
| Auth.Jwt.Issuer | string | hc-framework | 同上 |
| Auth.Jwt.AccessTTL / RefreshTTL | duration | 1h / 720h | 校验时用于区分 token 类型(仅校验用) |
| Captcha.Enabled | bool | false | 是否启用注册/登录验证码 |
| Captcha.Provider | string | turnstile | turnstile / recaptcha / hcaptcha / tencent |
| Captcha.SiteKey | string | "" | 前端渲染用 |
| Captcha.SecretKey | string | "" | 服务端校验用 |
| Captcha.AppID | string | "" | tencent 专用 |
| Security.IPLimitEnabled | bool | false | 注册/登录 IP 限频开关(进程内窗口,单实例有效) |
| Security.IPLimitPerMinute | int | 30 | 每 IP 每分钟最大请求数 |
| HcRpc.Etcd.Hosts | []string | [127.0.0.1:2379] | 发现 hc-rpc |
| HcRpc.Etcd.Key | string | hc.rpc | 与 hc.yaml 的 Etcd.Key 对应 |
| Prometheus.Host / Port | - | 0.0.0.0:9100 | 网关指标端点 |

启动:`cd app/gateway/api && go run gateway.go -f etc/gateway.yaml`(或 `make run-gateway`)。

## 3. 直连模式(无 etcd)

把上述 `Etcd` 段替换为 `Target`,即可不经 etcd 直连(本地开发/单机部署):

```yaml
# hc.yaml
Etcd: {}                      # 可留空或删除
# gateway.yaml 的 HcRpc 段改为:
HcRpc:
  Target: direct://127.0.0.1:8001
```

## 4. 生产切换 MySQL/PostgreSQL

1. 改 `hc.yaml` 的 `DB.Driver` 与 `DB.Dsn`,例如:

```yaml
DB:
  Driver: mysql
  Dsn: "user:pass@tcp(127.0.0.1:3306)/hc?charset=utf8mb4&parseTime=True&loc=Local"
```

2. 表结构复用仓库 `migrations/`(与 gin 版一致,go-zero 版启动时 `AutoMigrate` 会保证 8 张表存在)。
3. sqlite 下各文件型数据库(`data/*.db`)仅用于零依赖起步,生产务必切独立数据库实例。
